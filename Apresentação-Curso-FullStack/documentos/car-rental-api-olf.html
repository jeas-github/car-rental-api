MVP

Sistema de Locação de Veículos

  • SLIDE 01

    • Visão Geral do Projeto

    Desenvolver um MVP de um sistema de Locação de Veículos, com foco na criação de uma API funcional.
  • SLIDE 02
  • MVP = Mínimo Produto Viável
  • API = Application Program Interface
  • Foco na criação de uma API funcional e bem estruturada.

    • Propósito do Projeto

    • Centralizar informações sobre clientes e frota
    • Automatizar processos de locação e devolução
    • Demonstrar viabilidade técnica e de negócio do produto
  • SLIDE 03
  • Validar a proposta de um sistema digital de locação de veículos focado na API do sistema capaz de:

    • Público Alvo do Projeto

    • Clientes: pessoas físicas que desejam alugar veículos de forma prática
    • Funcionários: responsáveis pelos cadastros e controle das locações.
  • SLIDE 04
  • Público-alvo é um grupo específico de pessoas com características em comum, como idade, gênero, interesses e renda, que são mais propensas a se interessar por um produto, serviço ou mensagem.

    • Objetivos do MVP

    • Implementar uma API REST que simula operações reais de locação
    • Demonstrar o funcionamento das principais funcionalidades do sistema.
    • Validar a viabilidade do projeto a partir de fluxos e testes automatizados
  • SLIDE 05
  • Sem anotações Importantes

    • Funcionalidades (Essenciais) do MVP

    • Gerenciamento de Clientes.
    • Gerenciamento de Veículos.
    • Locação de Veículos.
  • SLIDE 06
  • Gerenciamento de Clientes: cadastro, edição, listagem e exclusão.
  • Gerenciamento de Veículos: controle de disponibilidade e dados da frota.
  • Locação de Veículos: registro de locações e devoluções.
  • Cálculo do Valor Total: baseado nas diárias e tempo de utilização.

    • Funcionalidades Futuras do MVP

    • Pagamento online.
    • Autenticação de usuários.
    • Relatórios e painel administrativo.
  • SLIDE 07
  • Sem anotações Importantes

    • Requisitos Funcionais

    • O sistema deve permitir o cadastro de veículos e cadastro de clientes.
    • Deve ser possível criar uma locação, informando veículo, cliente e datas (retirada/devolução).
    • O sistema calculará automaticamente o valor total da locação.
    • Não será permitido alugar um veículo já em uso.
    • Todos os dados devem ser persistidos em um banco relacional MySQL.
  • SLIDE 08
  • Sem anotações Importantes

    • Requisitos Não Funcionais

    Tecnologia Descrição
    Node.js Assíncrono, performance elevada para APIs
    TypeScript Tipagem estática, produtividade e escalabilidade
    Fastify Servidor Backend. Foco em velocidade e baixo overhead
    Prisma ORM Modelagem e manipulação de dados.
    MySQL Banco relacional robusto
  • SLIDE 09
  • Backend será construído com Node.js, TypeScript e Fastify.
  • Prisma ORM fará a comunicação com o MySQL.

    • Abordagem Code First do Prisma: O desenvolvedor define as entidades (tabelas), campos (colunas) e relacionamentos usando classes ou estruturas de dados no seu código, em vez de escrever SQL diretamente.
